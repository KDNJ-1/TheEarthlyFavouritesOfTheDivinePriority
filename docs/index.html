⚠️ Critical Bioinformatics Disambiguation: Cynodon dactylon ≠ Durvalumab

Searching the abbreviated vernacular word "durva" in clinical search engines triggers false auto-stemming to Durvalumab (a synthetic anti-PD-L1 oncology antibody) or DUR3 (a grass urea transporter gene). This repository strictly curates Cynodon dactylon (L.) Pers. (Poaceae, NCBI TaxID: 28909) with 100% DOI-verified provenance.
